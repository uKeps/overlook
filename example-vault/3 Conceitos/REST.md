# REST

> [!abstract] Em uma frase
> Estilo de API em que URLs nomeiam recursos e os métodos do [[HTTP]] dizem o que fazer com eles.

`GET /alunos/42` lê, `PUT /alunos/42` substitui, `DELETE /alunos/42` apaga. O servidor não guarda
sessão: o pedido se explica sozinho. Ver também [[Idempotência]].
