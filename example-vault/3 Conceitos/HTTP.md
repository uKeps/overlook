# HTTP

> [!abstract] Em uma frase
> Protocolo de pedido e resposta sem estado: cada requisição carrega tudo que o servidor precisa para respondê-la.

Um pedido tem **método**, **caminho**, **cabeçalhos** e corpo opcional. A resposta volta com um
**código de status** e o corpo. Quem quer estado entre pedidos usa cookie ou token.

Base de [[REST]] e de quase toda [[Cache HTTP]].
